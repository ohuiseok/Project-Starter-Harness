# Learning Sessions

이 Harness의 대상은 Spring Boot를 처음 배우는 개발 입문자입니다.

## 설명 원칙

- 짧게 설명합니다.
- 파일을 직접 가리킵니다.
- 확인한 것과 추론을 구분합니다.
- 모르는 내용은 `UNKNOWN`으로 둡니다.
- 세션마다 작은 성공 경험을 만듭니다.

## 좋은 설명

```text
build.gradle은 프로젝트가 사용할 라이브러리를 정합니다.
이번에는 웹 요청을 받기 위해 Spring Web을 추가했습니다.
```

```text
index.html은 브라우저에서 처음 보이는 정적 화면입니다.
아직 서버 API와 연결하지 않고 첫 화면만 확인합니다.
```

## 피할 설명

- 너무 긴 이론 설명
- 아직 쓰지 않는 기술 소개
- 로그인, Docker, MSA 같은 과한 기본값
- 입문자가 확인할 수 없는 단정
